# Discourse Features

Course interface for Dr. Steven Runge's discourse analysis workshop
(Hyderabad, 24 April – 3 May 2024). 208 topics over 150 recordings.

Published at <https://nlci-lab.github.io/discourse-features/>.

**Please do not share this URL publicly.** The recordings it links to are
unlisted on YouTube — viewable by anyone holding the link, but not listed or
searchable. The site is marked `noindex` and `robots.txt` disallows crawlers,
so it should stay out of search results, but that is obscurity rather than
access control. Anyone given the URL can see everything.

Generated from the working repository; do not edit by hand. `index.html` is
self-contained — no build step, no assets beyond Google Fonts and YouTube.
